1. Preparation

1.1 Required Preparation Items

  • A Frame Grabber that supports the CameraLink protocol is required.
  • Connection may be difficult if the Frame Grabber does not meet the specifications below.
  • GenICam(GenApi) : Ver_2.3.1
  • SFNC : Ver_2.0.0
  • GenICam_CLProtocol_Standard : Ver_1.1

1.2 SDK

  • CREVIS CameraLink cameras can be connected and configured using the SDK provided by CREVIS.
  • CREVIS SDK download link: CamGuideCL.zip

1.3 Precautions

  • Operating temperature: 0 deg C to +45 deg C
    Keep the ambient temperature stable because data output may vary according to temperature changes.
  • Leakage and humidity caution
    The product itself is not waterproof, so avoid exposing it to excessive humidity.
  • Magnetic and electric fields
    Because the I/O signals use low-voltage, low-current LVDS around 300 mV, strong magnetic or electric fields may distort the signals.
  • Ventilation
    Power consumption differs depending on the usage environment, but because power consumption is high, do not seal the area around the product or block airflow; maintain proper ventilation.
  • Initial operating condition
    When applying power to the product, apply power only after the cable is connected between the camera and the Frame Grabber.
  • Product performance may vary depending on cable characteristics.
  • To comply with CE standards, use a standard Camera Link cable or an equivalent high-shield cable. Recommended cable: 3M 14B26-SZLB-xxx-SKC.
  • This product may be changed without notice for functional and performance improvements.

4. Camera Functions

4.1 Image Format Control

4.1.1 Device Tap Geometry

This function sets Device Tap Geometry.

The Frame Grabber camfile must be changed according to the configured CameraLink Tap Geometry.

4.1.2 ROI

WidthMAX >= Offset X + Width
HeightMAX >= Offset Y + Height

By setting Width, Height, Offset X, and Offset Y, the user can receive only the desired area. The frame rate increases as the image size becomes smaller.

4.1.3 Reverse X, Y

This function changes the left/right and top/bottom orientation of the image.

  • In Reverse X mode, the image is flipped left/right.
  • In Reverse Y mode, the image is flipped top/bottom.
  • When 'Reverse Y' is selected, use of the Defect Filter is limited and defective pixels may appear.

Figure 1 - Reverse Image

4.1.4 ADC Bit Depth

This function changes the bit depth of the image output from the sensor. It can be set to 8-bit, 10-bit, or 12-bit.

In 8-bit mode, the image is approximately four times brighter than in 10-bit or 12-bit mode.

4.1.5 Pixel Format

This function changes the image format output from the camera. Only 8-bit RGB mode is supported.

4.1.6 Test Pattern

Displays a test pattern image.

  • Off: normal image
  • On : Test Pattern

Figure 2 - Test Pattern Image

4.3 Exposure Control

4.3.1 Exposure Mode

This function determines the exposure method.

ModeDescription
TimedExposes for the configured time value.
Trigger WidthExposes for the pulse width of the input trigger signal.
If Trigger Activation is Rising Edge, exposure lasts while the value is High; if Falling Edge, exposure lasts while the value is Low.

4.3.2 Exposure Time

Sets the exposure time. This applies only when the camera is set to Timed mode.

  • SHTSET: adjustable in 1 us units. (range: 0x1 to 0xFFFFFFFF, command used in CamGuideCL)

Note: actual exposure time = setting time + 14.26 us (when set to 1 us, exposure is 15.26 us)

Note: Exposure Start/End Delay: 3 HDs (52 us based on Base RGB8; varies depending on ROI and CL Configuration.)

Note: Delay from Exposure End to the start point of FVAL: (31 + ROI OffsetY) HD

4.3.3 Exposure Auto

Off: sets Gain manually.
Once: adjusts the Gain value only once to change the image to the desired brightness value.
Continuous: continuously adjusts the Gain value to maintain the desired brightness value.

When Gain Auto is used together with AutoExposure, the priority is as follows.

  1. When the image becomes brighter: Exposure control is applied first, then Gain is set.
  2. When the image becomes darker: Gain Control is applied first, then Exposure is set.

※ Analog gain [dB] = Register setting value / 10
