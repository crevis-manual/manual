1. Preparation

1.1 Required Items

  • A frame grabber that supports the CameraLink protocol is required.
  • If the frame grabber does not meet the following requirements, the camera may not connect.
Item Required Version
GenICam(GenApi) Ver_2.3.1
SFNC Ver_2.0.0
GenICam_CLProtocol_Standard Ver_1.1

1.2 SDK

  • Crevis CameraLink cameras can be connected and configured using the SDK provided by Crevis.
  • Crevis SDK download link: http://www.crevis.co.kr/kor/support/download/CamGuideCL.zip

1.3 Precautions

  • Operating temperature: 0 C to +45 C. Keep the temperature stable because image data output can vary with ambient temperature changes.
  • Water leakage and humidity: The product is not waterproof. Avoid exposing it to excessive humidity.
  • Magnetic and electric fields: The input/output signals use LVDS-level small voltage/current around 300 mV. Strong magnetic or electric fields may distort the signal.
  • Ventilation: Power consumption varies by environment, but the product can consume significant power. Do not enclose the product or block airflow; keep it ventilated.
  • Initial operation: Apply power only after the camera and frame grabber are connected with the cable.
  • Product performance can vary depending on cable characteristics.
  • To comply with CE requirements, use a standard Camera Link cable or an equivalent cable with good shielding. Recommended cable: 3M 14B26-SZLB-xxx-SKC.
  • This product may be modified without notice to improve functions and performance.

4.1.1 ROI (Region Of Interest)

By setting Width, Height, Offset X, and Offset Y, only the desired image area can be output. The frame rate increases as the output image size becomes smaller.

Note

  1. The frame rate changed by ROI can be checked through the Resulting Frame Rate parameter.

4.1.2 Reverse X, Y

This feature flips the image horizontally or vertically.

  1. When Reverse X is set to True, the image is flipped left and right. (Bayer RG -> Bayer GR)
  2. When Reverse Y is set to True, the image is flipped top and bottom. (Bayer RG -> Bayer GB)

Precautions

  1. When Reverse Y is selected, Defect Filter use is limited and defective pixels may appear. Exposed defective pixels can be removed in the Defect Pixel Correction category.
  2. When ROI and Reverse are used together, ROI is applied to the reversed image. When Reverse is enabled, the image start coordinate (0,0) is reversed. To capture the same region as before Reverse is applied, the image offset must be set to Total Size - ROI Size.

4.1.3 Pixel Format

This feature changes the image pixel format. Because each pixel format transfers a different amount of image data, transfer speed and bandwidth can vary.

4.1.4 Output Format Selector

  • AoP: Outputs the average angle of light entering the sensor. DN values change depending on the angle of the imaged object.
  • DoLP: Outputs the degree of polarized light entering the sensor as a brightness value. More polarized light produces a more saturated image.
  • Intensity(S0): Outputs the intensity of light entering the sensor. This is the same representation method used by standard monochrome cameras.
  • 0, 45, 90, 135 Degree: The image becomes more saturated as the incident angle approaches the selected degree value.
  • Example) 0 Degree: The image becomes more saturated as the incident angle approaches 0 degrees.
