1. 준비하기

1.1 필수 준비 요소

  • CameraLink 프로토콜을 지원하는 Frame Grabber가 필요합니다.
  • Frame Grabber가 하기 사양을 충족하지 못하는 경우 연결이 안될 수 있습니다.
  • GenICam(GenApi) : Ver_2.3.1
  • SFNC : Ver_2.0.0
  • GenICam_CLProtocol_Standard : Ver_1.1

1.2 SDK

  • 크래비스 CameraLink 카메라는 크래비스에서 제공하는 SDK를 이용하여 카메라 연결 및 카메라 환경 설정이 가능합니다.
  • 크래비스 SDK 다운로드 링크 : CamGuideCL.zip

1.3 주의사항

  • 동작 온도 : 0℃ ~ +45℃
    주변 온도 변화에 따라 데이터 출력이 변할 수 있으므로 일정하게 온도를 유지하십시오.
  • 누수 및 습기 주의
    제품 자체에 방수 기능이 없으므로 지나친 습기에 노출되지 않도록 주의하셔야 합니다.
  • 자기장 및 전기장
    입출력 신호가 “LVDS”로 300mV대의 미소 전압 및 전류이므로 강한 자기장 및 전기장에 노출되면 신호 왜곡이 발생할 수 있습니다.
  • 환기
    제품 주변을 밀폐하거나 공기 흐름을 차단하지 말고 통풍성을 유지하여야 합니다.
  • 초기 동작 상태
    Camera와 Frame Grabber에 Cable이 연결된 상태에서 제품 전원을 인가해야 합니다.
  • 제품 성능은 Cable 특성에 따라 달라질 수 있습니다.
  • CE 규격 준수를 위해 표준 Camera Link™ Cable 또는 동급 이상의 Shield 특성이 좋은 케이블을 사용해야 합니다. (추천 Cable : 3M 14B26-SZLB-xxx-SKC)
  • 제품의 기능 및 성능 개선을 위해 예고 없이 수정될 수 있습니다.

4. 카메라 기능

4.1 Image Format Control

4.1.1 Device Tap Geometry

Device Tap Geometry를 설정하는 기능입니다. 해당 Tap에 맞게 Frame Grabber camfile을 변경해야 합니다.

4.1.2 ROI (Region Of Interest)

WidthMAX ≥ Offset X + Width
HeightMAX ≥ Offset Y + Height

Width, Height, Offset X, Offset Y를 설정함으로써 사용자가 원하는 영역만 받는 것이 가능합니다. 또한, 사이즈가 작아질수록 fps가 증가합니다.

4.1.3 Binning Vertical

수직의 2-Pixel을 합하여 Frame Rate 속도가 2배가 되도록 설정하는 기능입니다.

4.1.4 Binning Horizontal Vertical (Only MC-A121M-67)

수평의 2-Pixel을 합하여 Frame Rate 속도가 증가하도록 설정하는 기능입니다. 단독으로 값을 조절할 수 없으며, Binning Vertical이 활성화되면 추가로 조절 가능합니다.

4.1.5 Decimation Vertical

수직으로 1-Pixel씩 건너뛰어 Frame Rate 속도가 2배가 되도록 설정하는 기능입니다.

4.1.6 Decimation Horizontal

수평으로 1-Pixel씩 건너뛰어 출력하여 Frame Rate 속도가 증가하도록 설정하는 기능입니다.

※ 모델별 Binning(Bin) 및 Decimation(Sub) 지원 현황

Image ModeMC-A500x-163MC-A121x-67
Binning VerticalO (Only Mono)O (Only Mono)
Binning Horizontal VerticalXO (Only Mono)
Decimation VerticalOO
Decimation HorizontalOO

4.1.7 Reverse X, Y

영상의 좌/우, 상/하를 변경하여 보는 기능입니다. Reverse X 모드 동작 시 영상의 좌/우가 바뀌며, Reverse Y 모드 동작 시 영상의 상/하가 바뀝니다.

‘Reverse Y’ 선택 시 Defect Filter 사용이 제한되며, 불량 화소가 나타날 수 있습니다.

4.1.8 ADC Bit Depth

Sensor에서 출력되는 영상의 Bit Depth를 변경하는 기능입니다. 8bit, 10bit, 12bit로 설정 가능합니다.

8bit 모드일 때 10bit 또는 12bit 설정 시보다 영상이 약 4배 밝아집니다.

4.1.9 Pixel Format

카메라에서 출력되는 영상의 Format을 변경할 수 있는 기능입니다. 모델별로 지원하는 Format이 다르므로 주요 사양을 확인한 후 설정하십시오.

4.1.10 Test Pattern

테스트 패턴 이미지를 보여줍니다. ‘Off’는 일반 이미지이며, ‘On’은 Test Pattern입니다.

4.2 Acquisition Control

4.2.1 Trigger Mode

Off : 카메라가 Freerun 모드로 동작합니다. Internal Trigger 신호가 생성되며 그 주기는 Acquisition Frame Rate에 의해 결정됩니다. Acquisition Frame Rate Enable이 Off이면 현재 설정에서 가능한 최대 Frame Rate로 동작합니다.

On : 카메라가 Trigger 모드로 동작합니다. Frame Grabber의 CC1~CC4(Line1~4), GPIO(Line5~6) 또는 Software Trigger를 통해 Trigger를 입력받을 수 있습니다.

ItemSetting ValueDescription
Trigger SourceLine1, Line2, Line3, Line4, Line5, Line6, SoftwareTrigger 입력으로 사용하고자 하는 Source를 선택합니다.
Trigger Delay0x1 ~ 0xFFFFFFFF
0 ~ 57,844,677µs		Trigger Delay를 조정합니다. (TRGDLY)
Line Debounce Time0x1 ~ 0xFFFF
0 ~ 882µs		Line Debounce Time을 조정합니다. (TRGFLTNUM)

4.2.2 Trigger Software

Trigger Mode를 ‘On’, Trigger Source를 ‘Software’로 설정하면 적용됩니다. Execute 시 Trigger Pulse를 하나 입력받아 영상 Frame을 한 장 취득할 수 있습니다.

4.2.3 Trigger Source

  1. Camera Link Connector — Line1~4 : CC1~CC4 핀을 통해 Frame Grabber에서 Trigger를 입력받습니다.
  2. 4pin Connector — Line5 : 2번 핀(GPIO1), Line6 : 3번 핀(GPIO2)을 통해 Trigger를 입력받습니다.
  3. Software Trigger — Software 함수를 통해 Trigger를 생성합니다.

4.2.4 Trigger Delay

Trigger 입력 후 사용자가 설정한 Delay 시간만큼 지연한 뒤 동작하도록 설정하는 기능입니다. TRGDLY 명령으로 µs 단위 조정이 가능합니다.

※ 1H = 74.25MHz(Global Model) 또는 72MHz(Rolling Model) × HMAX (RHMAX 명령어 또는 CamGuideCL에서 확인)

※ Hardware Delay : < 2µs (4.3.1 참고)

4.2.5 Line Debounce Time

외부 I/O로 전송된 Trigger 신호의 채터링 노이즈를 필터링하는 기능입니다. Line Debounce Time보다 폭이 짧은 Trigger Signal을 노이즈로 간주하여 필터링합니다. TRGFLTNUM 명령으로 µs 단위 조정이 가능합니다.

4.2.6 Fine Shutter Enable (Unit Control)

Pixel Clock 기준으로 노광 시간을 1µs 단위로 조절하도록 지원하는 기능입니다. ‘On’일 때는 µs 단위, ‘Off’일 때는 HD 단위로 조절합니다.

4.2.7 Exposure Mode

카메라 노광 방식을 결정하는 기능입니다.

ModeDescription

4.2.8 Exposure Time

노광 시간을 설정합니다. Timed 모드로 설정되어 있을 때만 적용됩니다. SHTSET 명령으로 µs 단위 조정이 가능합니다. (Range : 0x1 ~ 0xFFFFFFFF)

※ 실제 노광 시간 : 설정 시간 + 13.73µs (2.2 주요 사양 참고)

Exposure Time을 자동 조정하여 사용자가 원하는 밝기를 일정하게 유지하는 기능입니다. Exposure Mode가 Timed로 설정되어 있을 때 사용할 수 있습니다.
