1. Preparation

1.1 Required Preparation Items

  • A Frame Grabber that supports the CameraLink protocol is required.
  • Connection may fail if the Frame Grabber does not meet the specifications below.
  • GenICam(GenApi) : Ver_2.3.1
  • SFNC : Ver_2.0.0
  • GenICam_CLProtocol_Standard : Ver_1.1

1.2 SDK

  • CREVIS CameraLink cameras can be connected and configured using the SDK provided by CREVIS.
  • CREVIS SDK download link: CamGuideCL.zip

1.3 Precautions

  • Operating temperature: 0 deg C to +45 deg C
    Keep the ambient temperature stable because data output may vary according to temperature changes.
  • Leakage and humidity caution
    The product itself is not waterproof, so avoid exposing it to excessive humidity.
  • Magnetic and electric fields
    Because the I/O signals use low-voltage, low-current LVDS around 300 mV, strong magnetic or electric fields may distort the signals.
  • Ventilation
    Do not seal the area around the product or block airflow; maintain proper ventilation.
  • Initial operating condition
    Apply power only after the cable is connected between the camera and the Frame Grabber.
  • Product performance may vary depending on cable characteristics.
  • To comply with CE standards, use a standard Camera Link cable or an equivalent high-shield cable. Recommended cable: 3M 14B26-SZLB-xxx-SKC.
  • Specifications and performance may be changed without notice for product improvement.

4. Camera Functions

4.1 Image Format Control

4.1.1 Device Tap Geometry

This function sets Device Tap Geometry. The Frame Grabber camfile must be changed to match the selected tap.

4.1.2 ROI (Region Of Interest)

WidthMAX ≥ Offset X + Width
HeightMAX ≥ Offset Y + Height

By setting Width, Height, Offset X, and Offset Y, the user can receive only the desired area. The frame rate increases as the image size becomes smaller.

4.1.3 Binning Vertical

This function combines two vertical pixels so the frame rate becomes twice as fast.

4.1.4 Binning Horizontal Vertical (Only MC-A121M-67)

This function combines two horizontal pixels to increase the frame rate. It cannot be adjusted independently and can be additionally adjusted when Binning Vertical is enabled.

4.1.5 Decimation Vertical

This function skips every other vertical pixel so the frame rate becomes twice as fast.

4.1.6 Decimation Horizontal

This function skips every other horizontal pixel in the output to increase the frame rate.

Note: Model-specific Binning (Bin) and Decimation (Sub) support status

Image ModeMC-A500x-163MC-A121x-67
Binning VerticalO (Only Mono)O (Only Mono)
Binning Horizontal VerticalXO (Only Mono)
Decimation VerticalOO
Decimation HorizontalOO

4.1.7 Reverse X, Y

This function changes the left/right and top/bottom orientation of the image. In Reverse X mode, the image is flipped left/right; in Reverse Y mode, it is flipped top/bottom.

When Reverse Y is selected, use of the Defect Filter is limited and defective pixels may appear.

4.1.8 ADC Bit Depth

This function changes the bit depth of the image output from the sensor. It can be set to 8-bit, 10-bit, or 12-bit.

In 8-bit mode, the image is approximately four times brighter than in 10-bit or 12-bit mode.

4.1.9 Pixel Format

This function changes the format of the image output from the camera. Supported formats differ by model, so check the main specifications before setting it.

4.1.10 Test Pattern

Displays a test pattern image. Off shows the normal image, and On shows the test pattern.

4.2 Acquisition Control

4.2.1 Trigger Mode

Off : The camera operates in Freerun mode. An internal trigger signal is generated, and its period is determined by Acquisition Frame Rate. If Acquisition Frame Rate Enable is Off, the camera runs at the maximum frame rate possible with the current settings.

On : The camera operates in Trigger mode. Triggers can be input through CC1 to CC4 (Line1 to Line4), GPIO (Line5 to Line6), or Software Trigger from the Frame Grabber.

ItemSetting ValueDescription
Trigger SourceLine1, Line2, Line3, Line4, Line5, Line6, SoftwareSelects the source to be used as the trigger input.
Trigger Delay0x1 ~ 0xFFFFFFFF
0 ~ 57,844,677µs		Adjusts Trigger Delay. (TRGDLY)
Line Debounce Time0x1 ~ 0xFFFF
0 ~ 882µs		Adjusts Line Debounce Time. (TRGFLTNUM)

4.2.2 Trigger Software

This applies when Trigger Mode is set to On and Trigger Source is set to Software. Executing it inputs one trigger pulse and acquires one image frame.

4.2.3 Trigger Source

  1. Camera Link Connector - Line1 to Line4: trigger input from the Frame Grabber through CC1 to CC4 pins.
  2. 4pin Connector - Line5: trigger input through pin 2 (GPIO1), and Line6: trigger input through pin 3 (GPIO2).
  3. Software Trigger - Generates a trigger through the software function.

4.2.4 Trigger Delay

This function delays operation by the user-set delay time after trigger input. It can be adjusted in microseconds with the TRGDLY command.

Note: 1H = 74.25 MHz (Global Model) or 72 MHz (Rolling Model) x HMAX. Check RHMAX command or CamGuideCL.

Note: Hardware Delay: < 2 us (see 4.3.1)

4.2.5 Line Debounce Time

This function filters chattering noise in trigger signals transferred through external I/O. Trigger signals shorter than Line Debounce Time are treated as noise and filtered. It can be adjusted in microseconds with the TRGFLTNUM command.

4.2.6 Fine Shutter Enable (Unit Control)

This function supports exposure-time adjustment in 1 us units based on Pixel Clock. When On, exposure is adjusted in microseconds; when Off, it is adjusted in HD units.

4.2.7 Exposure Mode

This function determines the camera exposure method.

ModeDescription
TimedExposes for the configured time value.
Trigger WidthExposes for the pulse width of the input trigger signal. If Trigger Active is Rising Edge, exposure lasts while the signal is High; if Falling Edge, exposure lasts while the signal is Low.

Note: Timing by Exposure Mode

4.2.8 Exposure Time

Sets the exposure time. This applies only when Exposure Mode is set to Timed. It can be adjusted in microseconds with the SHTSET command. (Range: 0x1 to 0xFFFFFFFF)

Note: Actual exposure time = setting time + 13.73 us (see 2.2 Main Specifications)

4.2.9 Exposure Auto

This function automatically adjusts Exposure Time to keep the brightness desired by the user. It can be used when Exposure Mode is set to Timed.

ItemSetting ValueDescription

OnceAdjusts exposure time once to change the image to the desired brightness value.
ContinuousContinuously adjusts exposure time to maintain the desired brightness value.
Auto Exposure Target0 ~ 255Sets the desired brightness value (DN, based on 8-bit).
Auto Exposure Time Lower Limit100µs ~ 3secMinimum automatically configurable Exposure Time (AEMIN). It cannot be greater than the Upper Limit.
Auto Exposure Time Upper Limit100µs ~ 3secMaximum automatically configurable Exposure Time (AEMAX). It cannot be less than the Lower Limit.

Note: Exposure Time setting values may vary depending on Width and ADC Bit settings.
