1. Getting Started

1.1 Minimum / Recommended PC Specifications

  1. CPU: Intel Core i3 (minimum), i5 or higher (recommended)
  2. RAM: 2GB or higher (minimum), 8GB or higher (recommended)
  3. O/S: Windows 7 (32bit/64bit) or higher
  4. LAN Card: Intel PRO/1000xT or higher
  5. VGA: FHD support (minimum), UHD support or higher (recommended)

1.2 SDK

  • To use the Kravis GigE camera, you can acquire images using the SDK provided by Kravis, or use an image library that supports GigE Vision (Cognex, HALCON, Euresys, CVB, etc.).
  • Crevis SDK download link: https://www.crevis.co.kr/Customer/download

1.3 Cable

  • A Category 5E or higher network cable is required for data communication.
  • DC 12V~24V power must be applied to the camera.
  • When using POE+ (Power Over Ethernet +), do not apply external power to the 12Pin connector.

1.4 Firewall and antivirus program

  • To ensure stable packet transmission, firewalls and antivirus programs must be turned off or exceptions made.
  • How to set up a firewall

1) Windows 7

Start ▶ Control Panel ▶ Windows Firewall ▶ Turn Windows Firewall on or off

2) Windows 8, 8.1, 10

Start ▶ Control Panel ▶ Windows Defender Firewall ▶ Turn Windows Defender Firewall on or off

1.5 Precautions

  • Operating temperature (Performance guarantee temperature)
    Case temperature: 0℃ ~ +45℃
    Sensor temperature: +15℃
  • Data output may vary depending on ambient temperature changes, so keep the temperature constant.
  • Depending on changes in surrounding temperature, power consumption due to sensor cooling may increase.
  • Connecting two or more cameras via an Ethernet hub may cause bandwidth issues.
  • UDP communication does not guarantee data transmission.
  • To reduce packet loss, refer to the Installation Guide provided when installing the SDK, then set up the camera and
    network card.
  • To use the filter driver, run it with administrator privileges.
  • CamGuide automatically runs with administrator privileges.
  • A large packet size minimizes packet loss. However, the camera packet size must be lower than the jumbo frame or jumbo packet size of the network card.
    # Recommended packet size = (Image_Width * n) + 36.
    (n must be within the range where the packet size does not exceed the jumbo frame.)
    Ex) Recommended packet size when transmitting an image with 1296 * 1032 resolution = (1296 * 6) + 36 = 7812
  • LED status window
    1) You can check the current status of the camera through the LED on the back of the camera.
    2) If the connection between the host and camera is limited or image acquisition fails, check the LED status.

  • Water leakage and moisture caution
    Since the product itself is not waterproof, avoid exposing it to excessive moisture.
  • Magnetic and electric fields
    If input/output signals are exposed to strong magnetic or electric fields, signal distortion may occur.
  • Ventilation
    Power consumption varies depending on the usage environment, but because power consumption is high, do not seal the area around the product or block airflow. Maintain proper ventilation.
  • The product may be modified without notice to improve its functions and performance.

2. Product specifications

2.1 Product Overview

  • Sony SWIR Sensor Camera
  • Supports ROI Scan and X, Y Reverse mode
  • Supports Freerun and Trigger Mode
  • Supports defective pixel correction function
  • Supports Shading Correction (Tile FFC) function
  • Supports Sharpness Enhancement function
  • Supports Contrast/Brightness function
  • Supports Sensor Cooling Auto Mode
  • GigE Vision Standard
  • Supports External Trigger Mode (via 12pin circular connector)
  • Status LED support
  • Power Supply: DC 12V ~ 24V (10.8 ~ 26.4V range supported) and PoE+

# APPENDIX.B

1. Install SDK

  • Download link: https://www.crevis.co.kr/Customer/download
  • Install the installation program appropriate for your operating system.
    MCam40_SDK_V4.7.4.7758(x64).exe: Installer for Windows 64-bit

2.1 Run CamGuide

  • Select Device View Tap.
  • If there is no camera in the GIGE::Interface_GigEVision list, click to recheck.

2.2 Select and Connect Camera: Double-click the camera you want to set up.

2.3 Camera settings

  • Select Feature Properties Tap.
    * For detailed explanation, refer to CamGuide manual.
